Politique de confidentialité

Mise à jour : 2 novembre 2026

Qui est responsable de vos données

Michael Cousin, éditeur de Lueur, [ADRESSE], [E-MAIL].

Ce que nous collectons et pourquoi

  • Pour traiter votre commande : nom, adresse de livraison, e-mail, téléphone. Base légale : le contrat de vente.
  • Pour répondre à vos messages : nom, e-mail et contenu du message envoyé via la page Contact. Base légale : votre demande.
  • Paiement : vos données de carte sont saisies directement chez Stripe. Nous ne les voyons jamais.
  • Liste d'attente : votre e-mail, si vous demandez à être prévenu(e) de l'ouverture. Il sert uniquement à vous envoyer ce message, puis il est supprimé dans les 3 mois. Base légale : votre demande.
  • Mesure d'audience : des chiffres anonymes sur la visite du site (pages vues, site d'où vous venez, pays, téléphone ou ordinateur, clics sur le panier). Aucun cookie, aucune adresse IP conservée, aucun profil. Ces chiffres servent seulement à améliorer la boutique.

Qui reçoit vos données

  • Stripe, pour le paiement.
  • Notre fournisseur et son transporteur, pour préparer et livrer votre colis (nom, adresse, téléphone). Notre fournisseur passe par la plateforme AliExpress : vos données de livraison peuvent donc être traitées hors de l'Union européenne.
  • Netlify, qui héberge le site et reçoit les messages du formulaire de contact.

Certains de ces prestataires sont situés hors de l'Union européenne. Les transferts sont encadrés par les garanties prévues par le RGPD (clauses contractuelles types ou cadre de protection des données UE-États-Unis).

Combien de temps nous les gardons

Les données de commande sont conservées 3 ans après votre dernier achat, et les factures 10 ans pour nos obligations comptables. Les messages de contact sont supprimés au bout d'un an.

Vos droits

Vous pouvez demander à accéder à vos données, les corriger, les supprimer, en limiter l'usage ou vous opposer à leur traitement, en écrivant à [E-MAIL]. Vous pouvez aussi saisir la CNIL (cnil.fr).

Cookies

Le site n'utilise aucun cookie. Notre mesure d'audience interne garde seulement, le temps de votre visite, une petite note dans votre navigateur pour ne pas compter deux fois la même visite ; elle s'efface quand vous fermez l'onglet.

Lueur

Le soin qui s'allume, le soir, chez vous.
